🌹 How Our Plant Codes Work

Every rose variety in our nursery is assigned a unique code for easy wholesale ordering and identification. For example: D1 BI HT F

  • First Part (e.g., D1): Variety Initial & Serial Number
  • Color Code (e.g., BI, R, Y, P): BI = Bicolor, R = Red, Y = Yellow, P = Pink, W = White, O = Orange
  • Rose Type (e.g., HT, FL, CL, MIN): HT = Hybrid Tea, FL = Floribunda, CL = Climber, MIN = Miniature
  • Fragrance (F): Indicates a fragrant variety (omitted if non-fragrant)
